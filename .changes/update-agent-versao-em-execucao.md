titulo: Atualizações disponíveis acompanham a versão que está no ar
---

O painel volta a oferecer uma release mais nova quando o código do instalador avançou, mas a aplicação ainda roda uma imagem anterior. A versão instalada vem do contêiner em execução; instalações antigas sem essa informação preservam o fallback legado. A validação do manifesto e das quatro imagens MCP continua obrigatória.
