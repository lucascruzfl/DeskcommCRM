titulo: Instalação nova do fork ativa a distribuição MCP automaticamente
---

Em uma VPS nova, o instalador existente escolhe a última release MCP validada,
usa as imagens publicadas e ativa o canal de atualização MCP sem configuração
manual. Se faltar release ou imagem, interrompe a instalação.
