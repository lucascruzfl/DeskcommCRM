titulo: Consultar relatório por etiqueta e registrar honorários pelo MCP
---
Tokens manager autorizados podem consultar o relatório agregado por etiqueta de conversa e registrar contratos e parcelas internas de honorários quando o módulo estiver instalado. Os handlers são compartilhados com as rotas HTTP. O cadastro não gera cobrança, pagamento ou integração financeira externa.
